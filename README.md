# Minimal Invoice Studio v2

A minimal, modern invoice generator with:

- Logo upload
- Invoice history
- Saved item/service library
- Paid amount
- Balance due amount
- PDF export using browser Print / Save as PDF
- Local browser storage
- Optional Supabase cloud backup / multi-device sync

## How to use locally

1. Extract the ZIP file.
2. Open `index.html` in your browser.
3. Add your business details and logo.
4. Create invoice items.
5. Add `Paid Amount` if the client paid part of the invoice.
6. The invoice preview will show `Balance Due`.
7. Click `Save Invoice`.
8. Click `Download PDF`, then choose `Save as PDF`.

## Saved Items

Go to **Saved Items** and add your common services/products.
Example:

- Logo Design Package
- Brand Identity Package
- Social Media Post Design
- Printing Design

In the invoice page, click **+ From Saved** to add a saved item quickly.

## Important local storage note

Without cloud setup, data is saved in the same browser using Local Storage. Data can be lost if you clear browser site data/cache, use incognito mode, or move to another device/browser.

## Optional Supabase cloud setup

This is needed for online backup and multi-device access.

### Step 1: Create Supabase project

Create a free Supabase project and copy:

- Project URL
- anon public key

Paste them inside `supabase-config.js`.

### Step 2: Create database table

In Supabase SQL Editor, run this SQL:

```sql
create table if not exists public.invoice_app_data (
  id bigint generated by default as identity primary key,
  user_id uuid not null references auth.users(id) on delete cascade,
  app_key text not null default 'main',
  data jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now(),
  unique(user_id, app_key)
);

alter table public.invoice_app_data enable row level security;

create policy "Users can read their own invoice app data"
on public.invoice_app_data
for select
to authenticated
using (auth.uid() = user_id);

create policy "Users can insert their own invoice app data"
on public.invoice_app_data
for insert
to authenticated
with check (auth.uid() = user_id);

create policy "Users can update their own invoice app data"
on public.invoice_app_data
for update
to authenticated
using (auth.uid() = user_id)
with check (auth.uid() = user_id);
```

### Step 3: Login and sync

Open the app, go to **Settings**, sign up or login, then use:

- `Upload Local Data to Cloud` to backup current browser data
- `Download Cloud Data` to restore cloud data on another device
